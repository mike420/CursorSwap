# 🖱️ Cursor Swap

Swap Valheim's mouse cursor for one of nine hand drawn cursors, or your own, at whatever size suits your screen.

Based on CursorSwapper by Azumatt, rebuilt on Jötunn with a list of cursors to choose from.

<br>

## 🔥 Features:

  * Nine cursors built in, picked from a list in the settings:
    * Arcane Dagger & Casting Hand
    * Cursed Dagger & Undead Hand
    * Cursed Liquid Skull
    * Dark Academia Green Book Arrow & Bronze Hand
    * Fairycore Crystal Arrow & Mossy Hand
    * Furries Brown Paw & Claw
    * Mummy Sarcophagus & Mummy Hand
    * Solarpunk Wooden Arrow & Glass Hand
    * Steampunk Mechanical Hand & Bloody Arrow
  * Add your own: put PNG images in `BepInEx/config/CursorSwap` and restart the game. Each one is added to the list by its file name.
  * Set the cursor size, from 16 to 128 pixels.
  * Clicks land on the cursor's tip, wherever it is in the image.
  * Switch back to the game's own cursor at any time with Vanilla.

<br>

## ⚙️ Configuration:

  * **Enable Plugin** (default `true`): turns the mod on or off. This is a local setting and needs a game restart.
  * **Cursor** (default `Arcane Dagger & Casting Hand`): the cursor to use, from the list. Vanilla is the game's own cursor.
  * **Cursor Size** (default `48`): how big the cursor is, in pixels, from 16 to 128. Does not change the Vanilla cursor.

Settings can be changed in game (with Configuration Manager or the mod settings menu) and take effect straight away.

<br>

## 🌐 Multiplayer:

  * Client side only. You can join any server with it, and other players do not need it.

## 💻 Installation:

### Automatic Install

  * Plugin is created to be installed with r2modman or Gale.
For Nexus downloads you will need to install manually.

### Manual Install

  * Un-zip and drag the `plugins` folder into your `BepInEx` folder.
